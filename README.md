# Blog de Jogos

## Descrição do Projeto

O projeto consiste no desenvolvimento de um blog voltado ao universo dos jogos eletrônicos. A plataforma terá como objetivo apresentar conteúdos sobre jogos clássicos e atuais de forma acessível e organizada.

O projeto será desenvolvido como uma aplicação web estática composta por três páginas principais:

- Página Inicial (Feed)
- Página de Postagem (Artigo)
- Página de Contato/Parcerias

## Objetivo

Criar um blog de jogos com uma interface organizada, acessível e visualmente relacionada ao universo gamer, permitindo que os usuários encontrem e consumam conteúdos sobre diferentes jogos.

## Escopo

### Dentro do escopo

- Página inicial com feed de conteúdos.
- Página individual para leitura de uma postagem.
- Página de contato/parcerias.
- Navegação entre as páginas.
- Organização de imagens e ícones.
- Identidade visual própria.
- Layout responsivo para diferentes dispositivos.

### Fora do escopo

- Sistema de login.
- Banco de dados.
- Sistema de comentários.
- Pagamentos.
- Aplicativo mobile nativo.
