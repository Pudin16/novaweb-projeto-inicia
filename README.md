# Projeto NovaWeb - Loja Virtual

## Descrição do Projeto

Este projeto tem como objetivo desenvolver uma loja virtual utilizando tecnologias de desenvolvimento web. O trabalho faz parte das atividades do curso do SENAI e contempla as etapas de planejamento, documentação, desenvolvimento do Front-End e organização do Back-End.
