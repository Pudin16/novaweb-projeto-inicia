\# Etapa 1



\## Projeto de Software



Um projeto de software envolve planejamento, desenvolvimento, testes e manutenção.



\## Script



É um código simples criado para executar uma tarefa específica.



\## Ciclo de Vida



\### Requisitos

Definição das necessidades do cliente.



\### Desenvolvimento

Criação do código.



\### Testes

Correção de erros e validação.



\### Entrega

Implantação para uso.



\## Escopo



Definir o escopo evita mudanças constantes e atrasos.
