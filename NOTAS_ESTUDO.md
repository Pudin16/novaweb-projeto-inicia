Etapa 1 
1. O que difere um "Projeto de Software" de um "Script/Código isolado"?

Um projeto de software é um conjunto organizado de atividades que envolve planejamento, levantamento de requisitos, desenvolvimento, testes, documentação e manutenção para criar uma solução completa. Já um script ou código isolado é um programa simples, desenvolvido para executar uma tarefa específica, geralmente sem planejamento detalhado, documentação ou preocupação com manutenção futura.

2. Ciclo de Vida Básico de um Projeto

Levantamento de Requisitos / Escopo: Identificação das necessidades do cliente, definição das funcionalidades e dos limites do projeto.
Desenvolvimento / Codificação: Etapa em que os programadores implementam o software com base nos requisitos definidos.
Testes / Qualidade: Verificação do funcionamento do sistema para identificar e corrigir erros, garantindo que o software atenda aos requisitos.
Entrega / Implantação: Disponibilização do software para o cliente ou usuários finais, incluindo instalação, configuração e início da utilização.

3. Alinhamento com a NovaWeb Studio

Definir um escopo fechado antes de iniciar a codificação é fundamental porque estabelece claramente o que será desenvolvido, evitando mudanças constantes durante o projeto. Isso reduz retrabalho, facilita o planejamento do tempo e dos recursos, mantém a equipe alinhada e aumenta as chances de entregar o software dentro do prazo e do orçamento previstos.
